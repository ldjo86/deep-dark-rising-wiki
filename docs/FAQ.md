# Deep Dark Rising — Questions fréquentes

## Quelle version installer ?

0.1.0, universal MC 1.21 and MC 26. Choisis celle qui correspond à ta version Minecraft ; lis la page CurseForge.

## Le guide a-t-il vérifié toutes les mécaniques ?

Non. Fichiers universels locaux Deep Dark Rising 0.1.0 pour Minecraft 26.x et 1.21.x inspectés en lecture seule, y compris leurs sous-JARs. Les comportements décrits restent à confirmer en jeu.

## Comment obtenir de l'aide ?

Lorsque le dépôt sera créé sur GitHub, signale la version du fichier, celle du jeu, ton chargeur et les étapes qui reproduisent le problème.
